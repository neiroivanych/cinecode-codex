CineCode Setup for macOS

Extract the whole ZIP with Archive Utility. Open INSTALL_CINECODE.command and
wait for “CineCode is ready.” Open the printed folder in Codex and type $cinecode.

Setup uses installed components first. It offers the official Homebrew setup
when a missing component needs it. Review any macOS password prompt normally.

This ZIP bootstrap is unsigned. If macOS blocks the .command after an attempt
to open it, open System Settings > Privacy & Security and use Open Anyway for
this file only if you trust the package and its source. See the official help:
https://support.apple.com/en-us/102445

Run the same setup again to repair a same-version install. Film projects and
state are preserved. A different installed version requires a separate folder.
The setup window shows the path to its diagnostic log if a check fails.
