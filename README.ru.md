# cinecode-codex

**Независимый адаптер сообщества для создания видео с CineCode в OpenAI Codex.**
**Экспериментальная альфа** · Бесплатно и с открытым исходным кодом · `0.1.3-alpha`.

## Что такое cinecode-codex?

Установите адаптер, откройте его папку в Codex и введите `$cinecode` в новом
чате. Так вы сможете работать с режимами CineCode Quick и Film в Codex.
В этом репозитории находятся интеграция с Codex и копия конкретной версии CineCode.

Адаптер для Codex создал и сопровождает [@neiroivanych](https://github.com/neiroivanych).
Это независимый проект сообщества и неофициальная интеграция. Проект не связан
с OpenAI и не одобрен OpenAI. Адаптер не заявляет об одобрении со стороны автора CineCode.

## Что такое CineCode?

[CineCode](https://github.com/sarpstar/cinecode) — открытый проект
**Сарпа Йылдыза (Sarp Yıldız, @sarpstar)** под лицензией MIT. Он задаёт процесс,
в котором агент помогает продумать сценарий или структуру, создать и анимировать
сцены в коде, добавить звук и собрать готовое видео.

## Что адаптер добавляет для Codex

- [Навык `$cinecode` внутри репозитория](.agents/skills/cinecode/SKILL.md) и
  [инструкции по работе с CineCode в Codex](docs/HOST_ADAPTATION.md).
- Зафиксированную версию CineCode, проверку целостности, проверку зависимостей
  и среды запуска, а также запуск локальных инструментов.
- Пошаговую установку и восстановление на Windows и macOS. Установщик
  записывает пути к проверенным инструментам для последующих команд из Codex.
- [Тесты и результаты квалификации](docs/QUALIFICATION.md) для поддерживаемых
  сценариев адаптера.

У адаптера ограниченная защита (`REDUCED_NO_HOOKS`). Он не подключает хуки
жизненного цикла. Решения о переходе к следующему этапу принимает владелец
проекта. Адаптеру не нужен ключ API.

## Что можно сделать

В исходном CineCode предусмотрены короткие фильмы, объясняющие ролики, реклама,
видео о продуктах, музыкальные клипы и более длинные проекты с работой по этапам.
Вы обсуждаете фильм и проверяете результат в чате, а агент собирает сцены в коде.
В этом процессе нет привычной монтажной шкалы времени. Полный список возможностей
есть в [исходном проекте CineCode](https://github.com/sarpstar/cinecode). Сквозные
проверки в Codex охватывают более узкий набор сценариев, описанный ниже.

## Рекомендуемая установка

Скачайте ZIP для своей системы со [страницы релиза cinecode-codex на GitHub](https://github.com/neiroivanych/cinecode-codex/releases/tag/v0.1.3-alpha).

### Windows

1. Скачайте `CineCode-Setup-Windows.zip`.
2. Распакуйте ZIP целиком.
3. Дважды щёлкните `INSTALL_CINECODE.cmd`.
4. Дождитесь сообщения `CineCode is ready`.
5. Откройте указанную папку `cinecode-codex` в Codex.
6. Начните новый чат и введите `$cinecode`.

### macOS

1. Скачайте `CineCode-Setup-macOS.zip`.
2. Распакуйте ZIP целиком.
3. Откройте `INSTALL_CINECODE.command`.
4. Дождитесь сообщения `CineCode is ready`.
5. Откройте указанную папку `cinecode-codex` в Codex.
6. Начните новый чат и введите `$cinecode`.

Установщик для macOS не подписан и не прошёл нотарификацию Apple. Если macOS
блокирует запуск, сначала попробуйте открыть файл, затем выберите
**System Settings → Privacy & Security → Open Anyway** («Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть»). Используйте этот
вариант только для пакета, скачанного со страницы официального релиза cinecode-codex по ссылке выше.

### Как работает установщик

Установщик проверяет компьютер, использует совместимые компоненты, которые уже
есть, и подготавливает недостающие из числа поддерживаемых. На Windows он может
использовать системный менеджер пакетов. Если система запросит разрешение,
следуйте её подсказкам. Установка завершается сообщением об успехе после проверок
CineCode. Повторный запуск установщика той же версии восстанавливает установку
и сохраняет проекты, состояние и другие пользовательские файлы.

Установщик проверен на серверах CI с Windows Server 2025 x64 и macOS 15.8.2
arm64. Проверки охватили установку, восстановление, подготовку проверенного
компонента, среду запуска и обнаружение навыка в репозитории. Если на Mac сначала
нужно установить Homebrew, установщик запрашивает явное согласие. Этот сценарий
нативно не квалифицирован. Загрузка через браузер с последующим открытием в
Finder и интерфейс Codex Desktop находятся вне объёма этих проверок. См.
[результаты квалификации](docs/QUALIFICATION.md) и
[техническое руководство по установке](installer/README.md).

## Расширенная установка вручную

Для ручной установки понадобятся Git и версия Codex с поддержкой навыков из
репозитория. Установите Python 3.9+, Node.js 22+, FFmpeg и ffprobe, а также Chrome,
Chromium или Edge. В `CHROME_PATH` можно указать путь к уже установленному
браузеру. Если Python у вас запускается командой `python3`, используйте её.
Продолжайте после успешного завершения каждой проверки.

~~~sh
git clone --branch v0.1.3-alpha --single-branch https://github.com/neiroivanych/cinecode-codex.git
cd cinecode-codex
python -B scripts/cc.py verify
python -B scripts/cc.py doctor
~~~

Откройте клонированную папку в Codex, начните новый чат и введите `$cinecode`.
[Навык из репозитория](.agents/skills/cinecode/SKILL.md) позволяет отдельно
проверить совместимость. Команда `doctor` проверяет зависимости, а для запуска
браузера указывает `NOT_RUN`. В [техническом руководстве](installer/README.md#runtime-launch-from-codex)
описано, как использовать файл среды запуска установщика в последующих командах.

## Пользовательские проекты

Когда вы описываете будущий фильм, навык выбирает Quick или Film по брифу и
сохраняет контрольные точки в `STATE.md` и заметках. Git игнорирует стандартную
папку `workspace/`. Если папка установки доступна только для чтения, задайте
отдельный каталог с правом записи через `--workspace`. Храните резервные копии
проектов и их состояния отдельно.

~~~sh
python -B scripts/cc.py init my-film --mode quick
python -B scripts/cc.py tool my-film make stills
~~~

## Границы квалификации

- Контроль качества CineCode может задержать выпуск намеренно лаконичного,
  тёмного или малоподвижного видео.
- Побайтовая воспроизводимость звука не проверена. В локальном проекте Quick
  утверждённый звук сохранили копированием потока без потерь после того, как
  CineCode при повторной генерации выдал другие байты аудио.
- Синтетические медиапроверки в CI охватывают Canvas и локально созданный тон.
  Внешние TTS, модели и материалы требуют отдельного явного согласия и
  предварительной проверки команды запуска.

Для проверок при сопровождении используйте `python -B -m unittest discover -s tests -v`.
Нативное обнаружение навыка и короткий медиатест запускаются отдельно по запросу.
Их объём описан в [результатах квалификации](docs/QUALIFICATION.md).
